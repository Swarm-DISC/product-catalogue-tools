More details

Product identifier IBP_CLI_2_
Definition Climatological model of ionospheric bubble probability
Input data IBIxTMS_2F, EFIx_LP_1B, AUX_F10_2, Bubble detection index of CHAMP vector magnetic field data (similar procedure as for IBIxTMS_2F)
Input time span Model based on magnetic data: Entire Swarm mission + Entire CHAMP mission; Model based on electron density data: Entire Swarm mission
Spatial representation Continuous in geographic longitude at a step size of 1°
Time representation 1 LT hour
Units N/A ([0-1]: probability)
Resolution 0.01
Uncertainty Refer to Stolle et al. (2024) (An empirical model of the occurrence rate of low latitude post-sunset plasma irregularities derived from CHAMP and Swarm magnetic observations. Space Weather, 10.1029/2023SW003809)
Quality indicator N/A
Data volume Approximately 400 kB per file
Data format
  • Coefficients of climatological model of ionospheric bubble probability based on magnetic data are stored in .cdf file
  • Coefficients of climatological model of ionospheric bubble probability based on electron density data are stored in .pth file
Output data Probability estimation by longitude, LT, day of year, F10.7
Output time span N/A
Update rate yearly
Latency < 3 months
Notes The coefficient file, the machine learning model file, the applicable forward modelling code (in Python), and related documentation are available at https://igit.iap-kborn.de/ibp/ibp-model
